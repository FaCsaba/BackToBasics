# Arrays & Iteration

Arrays are an ordered collection of elements of the same size, accessible by an *index*.
The memory address of each element can be computed based on `address of 1st element` + `index of element` * `size of element`

| Aspect     | Value   |
|------------|---------|
| Homogenius | True    |
| Linear     | True    |
| Size       | Fixed   |
| Order      | Ordered |

# Dynamic Arrays

Built on top of Arrays, Dynamic Arrays are able to grow or shrink in size.

| Aspect     | Value   |
|------------|---------|
| Homogenius | True    |
| Linear     | True    |
| Size       | Dynamic |
| Order      | Ordered |
